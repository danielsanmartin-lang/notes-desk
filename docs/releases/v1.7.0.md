PoCs get their own documents, and you can correct the date a PoC's trial ended.

## Changes

- **Documentos de la PoC**: every PoC page has a new section, below the HubSpot deal, to attach any file (PDF, images, presentations, spreadsheets…).
  - Drag files onto the section or click **Añadir**. They are listed in the order you attached them, with the date and size.
  - Double-click a file (or use **Abrir**) to open it with its Mac app, or show it in Finder. **Abrir carpeta** opens the PoC's folder: files you drop there from Finder show up too.
  - Removing a file sends it to the Trash. Deleting a PoC sends its documents to the Trash as well.
  - RFPs keep their **Documentación** section as before.
- **Editable end date for finished PoCs**: if you marked a PoC as finished on the wrong day, click the date in the "Prueba finalizada" banner (or "Fin el …" under the start date) to change it.
  - Works for finished, won and lost PoCs. The date can't be in the future or before the start date.
  - The history, the week view and the average duration in Estadísticas follow the new date.

## Install or update

1. Download `Notes-Desk-1.7.0-mac-arm64.zip` (Mac with Apple Silicon) and unzip it.
2. Quit Notes Desk and drag **Notes Desk.app** into **Applications** (it replaces the previous one; your data is kept).
3. The app is ad-hoc signed, not notarized by Apple. The first time, right-click it → **Open**. If macOS says it is damaged, run:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/Notes Desk.app"
   ```
