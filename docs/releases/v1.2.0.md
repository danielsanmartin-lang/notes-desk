New version of **Notes Desk**: subtasks with their own counter and accounts linked to HubSpot.

## What's new

- **Subtasks with their own counter**: an item can have several subtasks and, while any is open, its counter (date, days waiting, touches) moves to each subtask. In lists, the item shows its subtasks below with their status and a "Touch" button; Home and Upcoming show the subtasks that are due. Each subtask supports "Log a touch" and "They replied", and its panel links to the parent item. When all are done, the item gets its counter back.
- **Accounts linked to HubSpot**: each account can have its HubSpot company ("Link to HubSpot" on its page; shortcut in the accounts list).
- **The company name on each item is a link**: it opens its HubSpot record or, if the account is not linked yet, the account inside the app.
- **"Today" is now called "Home".**
- In Follow-ups, an item with subtasks counts as "waiting" only if all its subtasks are.

## Install or update

1. Download `Notes-Desk-1.2.0-mac-arm64.zip` (Mac with Apple Silicon) and unzip it.
2. Drag **Notes Desk.app** into **Applications** (it replaces the previous one; your data is kept).
3. The app is ad-hoc signed, not notarized by Apple. The first time, right-click it → **Open**. If macOS says it is damaged, run:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/Notes Desk.app"
   ```
