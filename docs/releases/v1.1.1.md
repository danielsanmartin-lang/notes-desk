Maintenance release of **Notes Desk**.

## Changes

- **Delete items in plain sight**: a trash icon on each item on hover and in its panel header. Deleted items go to the Trash, with "Undo".
- **New projects without automatic tasks**: creating a project no longer adds the template checklist. If a project has no tasks, a button lets you use it whenever you want (the template is still edited in Settings).
- **Subtler PoC label**: in Today, Upcoming, Follow-ups and Accounts, only the word "PoC" is a label; the project name is plain text.

## Install or update

1. Download `Notes-Desk-1.1.1-mac-arm64.zip` (Mac with Apple Silicon) and unzip it.
2. Drag **Notes Desk.app** into **Applications** (it replaces the previous one; your data is kept).
3. The app is ad-hoc signed, not notarized by Apple. The first time, right-click it → **Open**. If macOS says it is damaged, run:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/Notes Desk.app"
   ```
