First version of **Notes Desk**: follow-ups, tasks and projects (PoCs) in a desktop app for macOS, with everything stored in a local SQLite database.

## What's in it

- **Today**: what to chase again, what is overdue, what is due today, starred items and everything without a date (project tasks included, with their project).
- **Follow-ups** with "whose turn it is": *My turn* / *Waiting for reply*, days without an answer, **Log a touch** (channel, note and next follow-up, never on a weekend), **They replied** and undo. Everything goes into each item's log.
- **Projects**: checklist from a template, owner, start date, client admins (with "Copy emails"), pause until a date with automatic resume and a link to the HubSpot deal (read-only sync with a `HUBSPOT_TOKEN`).
- **Accounts**: each company with its follow-ups, tasks, projects, contacts and history.
- **Stats**: weekly activity, reply rate and time, waits by age, channels, most active accounts and projects.
- **Weeks**: automatic archive per ISO week (W44…) with "Copy summary".
- **Quick capture** with ⌥Space from any app, and a type and date menu while typing, with dates in Spanish ("FUP Catalina BCI el viernes", "Kickoff @acme jueves 10:00").
- Menu bar icon, daily digest and native reminders, ⌘K search, trash, light/dark mode and daily backups.

## Install

1. Download `Notes-Desk-1.0.0-mac-arm64.zip` (Mac with Apple Silicon) and unzip it.
2. Drag **Notes Desk.app** into **Applications**.
3. The app is ad-hoc signed, not notarized by Apple. The first time, right-click it → **Open**. If macOS says it is damaged, run:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/Notes Desk.app"
   ```

Your data lives in `~/Library/Application Support/Notes Desk/` and is not touched when you update the app.
