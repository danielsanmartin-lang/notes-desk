New version of **Notes Desk**: light or dark mode, six colour themes and each project's history with its tasks.

## What's new

- **Appearance** (Settings, first card):
  - **Mode**: System (follows macOS), Light or Dark. In the app it also changes the sidebar's translucent background.
  - **Themes**: Electric (electric blue), Ocean (petrol and turquoise), Forest (green), Coral (warm), Lavender (violet) and Graphite (black and white), each with a light and a dark version. Settings shows a thumbnail of each.
  - The change shows instantly and the app opens with the chosen theme, without a flash.
  - All themes have enough contrast on buttons, links and secondary text. Charts and warning colours don't change with the theme.
- **Project history with its tasks**: each task shows from the moment it is added ("Task added"), next to touches, replies, notes, completions and pauses. Items in the trash don't show.

## Install or update

1. Download `Notes-Desk-1.4.0-mac-arm64.zip` (Mac with Apple Silicon) and unzip it.
2. Drag **Notes Desk.app** into **Applications** (it replaces the previous one; your data is kept).
3. The app is ad-hoc signed, not notarized by Apple. The first time, right-click it → **Open**. If macOS says it is damaged, run:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/Notes Desk.app"
   ```
