The app is now called **Notes Desk**.

## Changes

- **New name**: the app, its menus, the menu bar icon and notifications say "Notes Desk".
- **Your data comes along**: the first time Notes Desk opens, it copies the database of the previous version into its own folder (`~/Library/Application Support/Notes Desk/`). The old folder is left untouched, so you can delete it once everything looks right.
- The first colour theme is now called **Electric**; if you had it selected, it stays selected.

## Install or update

1. Download `Notes-Desk-1.5.1-mac-arm64.zip` (Mac with Apple Silicon) and unzip it.
2. Quit the previous version and drag **Notes Desk.app** into **Applications**. You can then delete the old app from Applications (if it was set to open at login, turn that on again in Notes Desk → Settings).
3. The app is ad-hoc signed, not notarized by Apple. The first time, right-click it → **Open**. If macOS says it is damaged, run:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/Notes Desk.app"
   ```
