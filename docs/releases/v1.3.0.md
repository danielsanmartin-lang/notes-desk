New version of **Notes Desk**: search on Home, project pause that works and project tasks added with one click.

## What's new

- **Search on Home** (⌘F): type one or more words to get the items, open and done, that contain them in the title, notes, company, contact, project, parent item or history. It ignores case and accents, highlights the words and, if the match comes from a note or the history, shows the snippet. Esc clears the search.
- **"Pause" works**: "Pause until…" did not open anything. Now the project's "Status" menu has "Pause", which pauses it right away, and "Resume" to undo it. While paused, its tasks don't show on Home or Upcoming; days open keep counting.
- **Project tasks**: the checklist template is replaced by three suggested tasks. They show as suggestions under each project's tasks and, with one click, move up as one more task. The ones the project already has are not offered again. They are edited in Settings → Project tasks.

## Install or update

1. Download `Notes-Desk-1.3.0-mac-arm64.zip` (Mac with Apple Silicon) and unzip it.
2. Drag **Notes Desk.app** into **Applications** (it replaces the previous one; your data is kept).
3. The app is ad-hoc signed, not notarized by Apple. The first time, right-click it → **Open**. If macOS says it is damaged, run:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/Notes Desk.app"
   ```
