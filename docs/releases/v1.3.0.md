Nueva versión de **Zepo Desk**: buscador en Inicio, pausa de PoCs que funciona y «Tareas de PoC» que se añaden con un clic.

## Novedades

- **Buscador en Inicio** (⌘F): escribe una o varias palabras y salen las tareas y follow-ups, pendientes y hechos, que las contienen en el título, las notas, la empresa, el contacto, la PoC, la tarea madre o el historial. No distingue mayúsculas ni acentos, resalta las palabras y, si el resultado sale de una nota o del historial, enseña el trozo donde aparece. Esc borra la búsqueda.
- **«Pausar» funciona**: «Pausar hasta…» no abría nada. Ahora el menú «Estado» de la PoC tiene «Pausar», que la pausa al momento, y «Reactivar» para volver. Mientras está en pausa, sus tareas no salen en Inicio ni en Próximos; los días abierta siguen contando.
- **Tareas de PoC**: la plantilla de checklist se sustituye por tres tareas (mandar instrucciones de whitelisting y guía, revisar si han creado usuarios y campañas, mandar follow-up PoC). Salen como sugerencias bajo las tareas de cada PoC y, con un clic, pasan arriba como una tarea más. Las que la PoC ya tiene no se vuelven a ofrecer. Se cambian en Ajustes → Tareas de PoC.

## Instalar o actualizar

1. Descarga `Zepo-Desk-1.3.0-mac-arm64.zip` (Mac con Apple Silicon) y descomprímelo.
2. Arrastra **Zepo Desk.app** a **Aplicaciones** (sustituye la anterior; tus datos no se tocan y la base se actualiza sola al abrir).
3. La primera vez, clic derecho → **Abrir**. Si macOS dice que está dañada:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/Zepo Desk.app"
   ```
