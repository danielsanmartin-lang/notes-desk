Fix for **Notes Desk**: "Pause" can be clicked again on a project page.

## Fixes

- **"Pause" can be clicked**: in the desktop app, the top of the page (the area used to drag the window) swallowed the clicks of the "Status" menu above it, and "Pause", the first option, did not respond. Menus, dropdowns and popovers now always get their clicks, whatever header they are over.

## Install or update

1. Download `Notes-Desk-1.3.1-mac-arm64.zip` (Mac with Apple Silicon) and unzip it.
2. Drag the app inside the zip into **Applications** (it replaces the previous one; your data is kept).
3. The app is ad-hoc signed, not notarized by Apple. The first time, right-click it → **Open**. If macOS says it is damaged, run:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/<app name>.app"
   ```
