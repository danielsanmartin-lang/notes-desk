New version of **Notes Desk**: what you write down for an account shows in its project, you know whether each follow-up goes to the client or the partner, and there is a new date, "In 3 working days".

## What's new

- **The project shows what you write down for its account**: tasks and follow-ups of the project's company that are not in it appear in a new block, "Noted in account X". They don't count towards progress. The project history also shows their activity (with a building icon) while the project is open.
- **"Move into project" with one click**: on those items (and on the account page), if the project is active. The item becomes a project task and counts towards its progress; the notice has "Undo". If the account has several active projects, you pick one.
- **Asks when creating**: if you type an item for a company with an active project, the field asks "Does it go to X's project?" with a button to move it in. If you ignore it, it stays in the account.
- **Client or partner**: in projects with a partner, each item says whether it goes to the partner.
  - It is set automatically if the title or contact names the partner ("partner", its name or its contact). What you already had is marked the same way when updating.
  - In the side panel, the "With whom: Client | Partner" row lets you change it.
  - The project card says "Client hasn't replied for N days" and "Partner hasn't replied for N days".
- **Next step in the project header**: with its date, even if it is an account item. Clicking it opens it.
- **"In 3 working days"**: a new date when creating an item and in the date picker; it skips the weekend. Typing "en 3 días laborables" or "hábiles" also works.

## Install or update

1. Download `Notes-Desk-1.5.0-mac-arm64.zip` (Mac with Apple Silicon) and unzip it.
2. Drag the app inside the zip into **Applications** (it replaces the previous one; your data is kept).
3. The app is ad-hoc signed, not notarized by Apple. The first time, right-click it → **Open**. If macOS says it is damaged, run:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/<app name>.app"
   ```
